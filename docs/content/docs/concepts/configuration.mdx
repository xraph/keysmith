Keysmith uses the functional options pattern for engine construction.

## The Config struct

The root package declares a `Config` struct:

```go
type Config struct {
    DefaultPrefix      string
    DefaultEnvironment key.Environment
    DefaultKeyLength   int
}
```

Nothing reads it yet: there's no option that takes it, and `CreateKey` uses the `Prefix` and `Environment` you pass in `CreateKeyInput` as they are. Set them on every create.

## Engine options

```go
eng, err := keysmith.NewEngine(
    keysmith.WithStore(store),
    keysmith.WithHasher(customHasher),
    keysmith.WithKeyGenerator(customGen),
    keysmith.WithRateLimiter(limiter),
    keysmith.WithExtension(auditPlugin),
    keysmith.WithLogger(logger),
    keysmith.WithMetrics(metrics),
)
```

| Option | Description |
| ------ | ----------- |
| `WithStore(store.Store)` | Required: `NewEngine` fails with "store is required" without it. Sets the composite store backend. |
| `WithHasher(Hasher)` | Custom key hasher. Defaults to SHA-256. |
| `WithKeyGenerator(KeyGenerator)` | Custom key generator. Defaults to `{prefix}_{env}_{64 hex}`. |
| `WithRateLimiter(RateLimiter)` | Rate limiter for validation. No default, and without one a policy's `RateLimit` is never checked. |
| `WithExtension(plugin.Plugin)` | Registers a lifecycle plugin. |
| `WithLogger(log.Logger)` | A `github.com/xraph/go-utils/log` logger. Defaults to a no-op logger. |
| `WithMetrics(metrics.Metrics)` | A `github.com/xraph/go-utils/metrics` sink for the engine's [metrics](/docs/subsystems/observability). Defaults to none, which records nothing. The Forge extension passes `app.Metrics()`. |

## Key format

The default key generator produces keys in the format:

```text
{prefix}_{environment}_{64 hex characters}
```

Example: `sk_live_a3f8b2c9e1d4f5a6b7c8d9e0f1a2b3c4d5e6f7a8b9c0d1e2f3a4b5c6d7e8f9a0`

## Pluggable interfaces

### Hasher

```go
type Hasher interface {
    Hash(rawKey string) (string, error)
    Verify(rawKey, hash string) (bool, error)
}
```

The default uses SHA-256 with constant-time comparison.

### KeyGenerator

```go
type KeyGenerator interface {
    Generate(prefix string, env key.Environment) (string, error)
}
```

### RateLimiter

```go
type RateLimiter interface {
    Allow(ctx context.Context, key string, limit int, window time.Duration) (bool, error)
    Remaining(ctx context.Context, key string, limit int, window time.Duration) (int, error)
}
```

The engine calls `Allow` with the key's ID. Keysmith ships no implementation.
